# Direct-generation brief

Before calling image generation, determine these fields internally:

- Author name and avatar source or generation direction.
- Two relevant badges and a plausible post time.
- One concise English title.
- Two to four short English body sentences.
- One story-specific media-card subject, style, crop, and key visual details.
- Optional short English media overlay.
- One concise English CTA.
- Plausible fictional like, comment, and share counts.
- One featured commenter, specific English comment, and like count.

Do not show this brief to the user and do not request confirmation. Generate the complete post immediately.

Use the template for UI layout and the current source for identity, subject, and story facts. Keep all visible text in English. Preserve supplied names and recognizable identity. Infer missing creative details conservatively from the current source only.
