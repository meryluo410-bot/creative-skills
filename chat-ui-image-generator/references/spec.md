# Approval brief

## Planning response

Before generating an image, provide:

1. The randomly selected female English contact name.
2. A numbered list or table containing every visible chat block in order.
3. For each block, identify the sender as `Agent / left` or `User / right`.
4. Include the exact English text for every text bubble.
5. Mark every media insertion at its exact position in the sequence.
6. Describe each media card's content, sender, form, and approximate dimensions.
7. State that the avatar will be a fictional, non-photoreal AI-art female character.
8. Ask the user to confirm or request edits.

Do not call image generation, create assets, or render a draft before confirmation.

## Direct-generation brief

After confirmation, generate the complete screenshot in one image-generation call with:

- Canvas: 1080 × 1920 PNG, 9:16.
- Interface: minimalist iOS-style fictional chat on white.
- Header: centered AI-art female avatar, approved English contact name, `Today`, close icon, menu dots.
- Messages: exact approved English text, in the approved order.
- Alignment: black outgoing blocks on the right; pale incoming blocks on the left.
- Media: embedded directly in the screenshot at the approved positions and proportions.
- Times: assign the fixed sequence `08:21`, `08:22`, `08:23`, `08:23`, `08:24`, `08:25`, `08:26`, `08:26`, `08:27`, `08:27`.
- Composer: `Message {name}` synchronized with the contact name.
- Safety: fictional presentation only; no implication that it is evidence of a real conversation.

Inspect the final image. Correct the complete screenshot if text, alignment, card sizing, or layout is wrong.
